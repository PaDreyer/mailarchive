# MailArchive 1.0.3

MailArchive 1.0.3 renews expired OAuth access tokens during mailbox scans for IMAP,
Gmail, and Microsoft Graph accounts. If a token expires while reading mail, the scan
can reconnect and continue without restarting from the beginning. IMAP also checks
that the folder identity has not changed after reconnecting.

Malformed sender and recipient address headers no longer stop an email from being
archived. MailArchive preserves the original header text where possible and includes
the email ID and error type when an individual message still fails.

Attachment-only rules now count matching emails with no attachments as skipped and
avoid creating empty destination folders. On Linux, reopening MailArchive from the
notification area preserves the application's dock identity.

The replacement 1.0.3 packages include the Pillow/Tk runtime modules needed to load
the window icon. This fixes the startup crash in the withdrawn Linux AppImage.
Package builds now create, hide, and restore a real window during their smoke tests;
Linux also checks the final AppImage before it can be published.

Existing account and rule settings remain compatible. The database and settings
schemas are unchanged, and previously archived mail remains intact.

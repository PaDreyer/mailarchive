# MailArchive 1.0.2

MailArchive 1.0.2 fixes the Windows application icon. The executable now includes the
MailArchive envelope icon, so desktop and Start menu shortcuts show the application icon
instead of PyInstaller's default icon. The installer also uses the MailArchive icon.

There are no changes to account configuration, archive rules, or the database and settings
schemas. Existing installations and archived mail continue to work unchanged.

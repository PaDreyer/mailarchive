# MailArchive 1.0.0

MailArchive 1.0.0 is the first stable release. Initial development is complete, and the
application is ready for everyday use.

This release marks that milestone with a version change from 0.2.1 to 1.0.0. It introduces
no changes to archiving behavior, configuration formats or database schemas.

MailArchive runs on Windows and Linux and archives emails and attachments from IMAP,
Gmail and Microsoft Graph into local folders. Existing settings, credentials and processing
history continue to work.

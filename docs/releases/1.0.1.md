# MailArchive 1.0.1

MailArchive 1.0.1 fixes the Linux notification-area integration. It now communicates directly
with StatusNotifier hosts instead of relying on the legacy Xorg tray protocol, which could fail
when GNOME changed views.

The release also completes the StatusNotifier interface expected by current GNOME AppIndicator
hosts and avoids leaving a startup loading indicator after reopening the window from the tray.

There are no changes to account configuration, archive rules, or the database and settings
schemas. Existing installations and archived mail continue to work unchanged.
